## 🎯 CHECKLIST RÁPIDO

### Primeira Instalação
```bash
# 1. Clone
git clone https://github.com/leanderdulac/ClimateWise.git
cd ClimateWise

# 2. Setup
./quick_start.sh

# 3. Verifique
./scripts/verify_platform.sh

# 4. Inicie
./start_platform.sh
```

### Deploy em Produção
```bash
# 1. Configure
cp .env.example .env
nano .env  # Edite variáveis

# 2. Gere SECRET_KEY
./scripts/generate_secret_key.sh

# 3. Deploy
docker compose -f docker-compose.prod.yml up -d

# 4. Verifique
./scripts/verify_platform.sh
```

### Backup
```bash
# Backup manual
./scripts/backup.sh

# Backup automático (adicionar ao crontab)
crontab scripts/backup-cron.txt
```

### Restore
```bash
# Listar backups
ls -lh backups/

# Restaurar
./scripts/restore.sh backups/climatewise_YYYYMMDD_HHMMSS.sql.gz
```
